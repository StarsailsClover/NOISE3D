## User Feedback (driver)

> "在用户体验与交互这一块你似乎没有很好的跟进 Blender。"

## Gap audit vs Blender interaction set

Four muscle-memory behaviors were missing entirely:

1. **Navigation axis gizmo** (top-right axis balls; click snaps to the
   axis view, drag orbits) -- present in both Blender and Unity; absent
   here.
2. **Live transform readout** during modal drag in the header/status
   area (`Dx: 1.2 Dy: 0.0 Dz: -0.5`).
3. **Mid-drag axis locking**: pressing X/Y/Z during a move constrains
   the drag to that axis, without pre-selecting it on the gizmo.
4. **Mid-drag precision**: Shift = 0.1x rate; typing digits enters an
   exact numeric value for the constrained axis; Enter commits.

Also: Outliner double-click = inline rename (we only had context-menu
rename).

## Scope for this increment

- `ViewportNavGizmo`: SVG axis balls (X/Y/Z + negatives), click = snap
  view, drag background = orbit. Driven by cameraRef via rAF.
- Gizmo drag: axis-lock keys, Shift precision, live `Dx/Dy/Dz` readout
  piped through a lightweight store slice into the status bar, numeric
  entry buffer (digits + Enter) for the constrained axis.
- Hierarchy double-click inline rename.

Deferred: pie menus, quad view, undo-history navigator (tracked for the
next Major's planning).
