# NOISE3D 交互体验路线图: v26.1-19.0 至 v26.1-28.0

## 动机

第二阶段 (v09-v18) 交付了功能广度, 但交互质量与 Unity/Blender 差距依然明显。
诊断出的核心缺陷:

1. **面板灾难** -- 左栏堆叠 6 个面板, 右栏 6 个, 全部常驻可见, 空间挤压。无工作区/标签页概念。
2. **半成品 Gizmo** -- 仅支持轴拖拽, 无拖拽平面; 悬停反馈弱; 每次鼠标移动都产生撤销记录而非合并为一次。
3. **原始的数值输入** -- 无拖拽滑动调节、无方向键微调、无提交/还原语义。
4. **无上下文菜单** -- 任何地方都没有右键菜单; 无快捷键速查; Escape 行为不一致。
5. **反馈回路缺失** -- 无状态栏操作提示、无悬停高亮、无 toast 通知、无拖放支持。

本阶段零新增"功能" -- 每个版本只深化交互质量。

## v26.1-19.0 -- 工作区系统

**问题:** 所有面板永远可见; 无关面板挤占视口空间。

### 规格
- 工具栏中央工作区标签: `Layout | Modeling | Shading | Animation | Rendering`
- 每个工作区面板可见性:
  - Layout (布局): Hierarchy, Viewport, Timeline, Console, Inspector
  - Modeling (建模): Hierarchy, Viewport, MeshEdit, Inspector
  - Shading (着色): Viewport, MaterialEditor, RenderSettings, Inspector
  - Animation (动画): Hierarchy, Viewport, Timeline, CurveEditor
  - Rendering (渲染): Viewport, RenderSettings, CodeEditor
- 活动工作区持久化到 localStorage
- 所有面板可通过点击标题折叠 (箭头指示)
- 折叠状态按工作区持久化
- 面板永不重叠或溢出; 中列保持 >= 50% 宽度

### 验收测试
- 切换工作区改变可见面板集合
- 工作区选择在页面刷新后保留
- 折叠面板仅显示标题条
- 每个工作区中视口占据 >= 50% 高度

## v26.1-20.0 -- Gizmo 交互打磨

**问题:** 仅轴拖拽; 无平面手柄; 每次 mousemove 产生一条撤销记录。

### 规格
- 移动 Gizmo 增加 3 个四边形平面手柄 (XY, XZ, YZ) 用于双轴拖拽
- 旋转 Gizmo 增加面向屏幕的外环用于相对相机旋转
- 悬停状态: 悬停的轴/平面变亮 + 光标变为 `grab`
- 拖拽中: 光标 `grabbing`; 轴线延伸为横跨视口的引导轨
- 撤销合并: 每次手势一条快照 (mousedown 时快照, 移动过程不再快照)
- 按 Ctrl = 吸附 (移动 0.5 单位 / 旋转 15 度); 显示吸附刻度指示
- Gizmo 屏幕像素尺寸恒定, 不随相机距离变化

### 验收测试
- 平面手柄拖拽同时沿两轴移动物体
- 一次拖拽手势 = 恰好一步撤销
- 拖拽时按住 Ctrl 值被量化
- 悬停部件在指针进入 50ms 内视觉可辨

## v26.1-21.0 -- 数值输入体验

**问题:** 裸数字输入框; 每次微调都要打字。

### 规格
- 新共享 `<NumberField>` 组件用于所有数值输入:
  - 在字段上水平点击拖拽滑动数值 (光标 `ew-resize`)
  - 上/下方向键按步进微调; Shift x10; Alt x0.1
  - Enter 提交; Escape 还原编辑前值
  - 双击全选文本
  - 非法输入静默拒绝 (保留最后有效值), 边框红色闪烁
- 滑块+数字组合: 拖滑块实时更新数字, 反之亦然
- 变换字段步进 0.1; 材质滑块保留自身范围

### 验收测试
- 标签向右拖 100px 按预期步数增加值
- 编辑后 Escape 精确还原原值
- 方向键聚焦导航无需鼠标
- 非法输入时红色闪烁可见

## v26.1-22.0 -- 上下文菜单与键盘语义

**问题:** 无右键菜单; Escape 行为不一致; 快捷键不可发现。

### 规格
- 右键上下文菜单:
  - 视口空白处: 添加 Cube/Sphere/Plane/Cylinder/Cone
  - 视口物体上: 复制 / 删除 / 聚焦 (F) / 隔离显示
  - 层级项: 重命名 / 复制 / 删除 / 移至根节点
  - 资源项: 添加到场景 / 移除资源
- 菜单通过点击外部、Escape 或执行动作关闭
- 统一 Escape 链: 取消 Gizmo 拖拽 > 关闭菜单 > 关闭命令面板 > 取消选择
- `?` (Shift+/) 打开快捷键速查弹窗, 按类别分组
- 所有菜单支持键盘导航 (方向键 + Enter)

### 验收测试
- 每个菜单在光标处打开且条目符合目标类型
- Escape 先关闭菜单再取消选择
- 速查表列出所有已注册快捷键
- 菜单项可纯键盘执行

## v26.1-23.0 -- 拖放流程

**问题:** 资源需双击添加; 文件需对话框浏览; 层级拖放无可视化指示。

### 规格
- 拖资源项 -> 放到视口在射线命中点实例化网格 (未命中则在原点)
- 拖系统文件 (.obj/.json/.png) 到窗口经现有管线导入
- 系统文件悬停时整窗高亮虚线边框覆盖层
- 层级拖拽显示插入指示: 上方/下方线条 (重排序) 或包围框 (重新设父)
- 无效放置目标显示 `not-allowed` 光标

### 验收测试
- 资源放到物体屏幕位置处, 新节点出现在对应世界位置
- OBJ 拖入窗口直接进入资源列表, 无对话框
- 指示器在重排序 vs 重新设父间有视觉区分
- 失败的放置不改变场景

## v26.1-24.0 -- 选择与悬停反馈

**问题:** 只有选中的线框; 无悬停状态; 多选不可见。

### 规格
- 光标下物体显示悬停轮廓 (细线, 30% 不透明度橙色), 射线节流 (~30Hz)
- 选中物体: 实线橙色轮廓; 多选择额外显示组周围的半透明 AABB 盒
- 视口中选择时层级项滚动到可视区 + 300ms 背景闪烁
- 层级中选择时物体下方绘制临时地面标记
- 空白处点击取消全选已有; 新增双击空白 = 全景取景

### 验收测试
- 悬停轮廓随指针移动出现/消失
- 多选显示包围盒
- 双向跨面板选择同步可观察
- 双击空白重新取景相机

---

## v26.1-25.0 -- 状态栏、提示与新手指引

**问题:** 用户无法得知鼠标按键作用; 首次使用无引导。

### 规格
- 常驻状态栏 (底部, 24px):
  - 左: 上下文相关鼠标提示 (`LMB Select | RMB Orbit | MMB Pan | Wheel Zoom`)
  - 中: 场景名 + 未保存更改时的脏标记圆点
  - 右: 节点数 | 光源数 | FPS
- 样式化工具提示 (深色卡片, 300ms 延迟) 替换所有工具栏/Gizmo/相机按钮的原生 title
- 首次运行引导: 4 步聚光灯覆盖层 (Toolbar > Hierarchy > Viewport > Inspector),
  "跳过"始终可用, 完成标记存 localStorage

### 验收测试
- Gizmo 模式切换时提示文字变化 (如 `LMB Drag X/Y/Z`)
- 首次编辑后脏点出现, 保存后清除
- 引导只显示一次; 跳过设置永久标记
- FPS 读数约每秒更新 2 次

## v26.1-26.0 -- 命令面板与搜索

**问题:** 每个操作都需要知道按钮在哪里。

### 规格
- `Ctrl+K` 打开模糊搜索命令面板:
  - 来源: 所有图元、视图预设、投影切换、保存/加载/新建/导出、Gizmo 模式、网格/播放切换、插件工具
  - 名称+关键词模糊匹配; Enter 执行首项; 方向键导航
  - 有快捷键的命令旁显示快捷键徽章
- 层级搜索框实时过滤树 (大小写不敏感子串)
- 面板记住最近执行的 5 条命令置于"最近使用"

### 验收测试
- 输入 "cub" 出现 "Add Cube"
- 经面板执行命令与按钮效果完全一致
- 使用后"最近使用"区填充
- Escape 关闭面板且不执行动作

## v26.1-27.0 -- 安全网: Toast、模态与自动保存

**问题:** 反馈埋在控制台; 破坏性操作无防护; 崩溃丢失工作。

### 规格
- Toast 系统 (右上角堆叠): info/success/warn/error, 自动消失 3s, 最多堆叠 5 条
  - 替换高价值控制台日志: 保存/加载/导出/插件事件
- 未保存更改防护: 有脏标记时 New Scene / Load / 窗口关闭弹出确认模态
- 确认模态组件替换所有 `confirm()` 用法
- 自动保存: 每 60s 存入 `noise3d:autosave` 槽; 启动时若自动保存晚于上次手动保存,
  提供"恢复自动保存?"toast, 含 Restore/Discard 按钮

### 验收测试
- 保存触发成功 toast; 错误路径触发错误 toast
- 脏标记 + New Scene 显示模态; Cancel 干净中止
- 模拟崩溃 (会话中刷新) 出现恢复选项
- 最多 5 条 toast 可见; 最旧的被移除

## v26.1-28.0 -- 性能与响应速度

**问题:** 帧预算未知; 多物体时 UI 卡顿; 层级渲染全部行。

### 规格
- 状态栏 FPS 低于 45 变琥珀色, 低于 30 变红色
- 所有面板主体 React.memo; store 选择器细化为基本类型切片
- 悬停射线限频 30Hz, 轨道/拖拽期间完全跳过
- 层级列表虚拟化 (仅渲染可见行 +/- 过扫描)
- 导入操作异步并在状态栏显示进度条
- 目标: 集成显卡上千节点场景保持 >= 55 FPS, 层级滚动流畅

### 验收测试
- 1000 立方体场景在测试环境中维持交互帧率
- 层级虚拟化用 DOM 行数断言验证
- 相机拖拽期间零悬停射线 (插桩计数)
- 大型 OBJ 导入期间进度条可见
