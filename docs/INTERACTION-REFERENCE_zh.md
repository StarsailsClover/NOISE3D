# 交互参考: Blender 与 Unity 模式

调研来源: Blender 开发者文档 (operator 系统)、`blender/blender` 的
`wm_operators.c`、Blender 手册 (输入字段、导航)、Unity 手册 (场景视图导航)。
本文将两个工具的已验证行为映射到 NOISE3D 的 UX 阶段
(v26.1-19.0 .. v26.1-28.0)。两者不一致时按版本择一采用并注明。

---

## 1. 模态算子模式 (Blender) -- Gizmo 拖拽的基础

Blender 的核心交互原语。每种拖拽型操作遵循:

```
invoke()  -> 快照状态, 注册模态处理器 -> RUNNING_MODAL
modal()   <- 接收每个事件直至终止事件
  MOUSEMOVE          : 将增量应用到工作副本
  LEFTMOUSE / ENTER  : 返回 FINISHED   (提交 + 单次撤销入栈)
  RIGHTMOUSE / ESC   : 返回 CANCELLED  (恢复快照状态, 不产生撤销)
```

我们必须复现的关键规则 (`ModalDragSession`):

| 规则 | 实现 |
|------|------|
| 一次手势 = 至多一条撤销记录 | mousedown 时快照; 移动过程不快照 |
| 取消精确还原 | 保留拖拽前的值; Esc/RMB 写回 |
| 确认提交 | LMB 抬起 / Enter 定稿 |
| 拖拽中实时数值反馈 | 状态栏显示增量 (如 "D: 1.20 along X") |
| 拖拽中的轴约束 | 拖拽中按 X/Y/Z 锁定轴 (v26.1-22 范围) |

源码证据: `WM_generic_select_modal` 区分点击 (选择) 与超过阈值的拖拽
(tweak) -- 采用 `点击 vs 拖拽阈值 = 4px`, 使点击选中物体不会抖动成微移动。

## 2. 数值字段行为 (Blender 手册, 已验证)

适用于 v26.1-21.0 `<NumberField>`:

| 交互 | 行为 |
|------|------|
| 悬停 | 字段边缘显示 `<` `>` 步进箭头 |
| 点击箭头 | 按单位步进 |
| 字段上 Ctrl+滚轮 | 无需点击直接步进 |
| LMB 水平拖拽 | 连续滑动调值 |
| 拖拽时按 Ctrl | 吸附到离散步长 |
| 拖拽时按 Shift | 精度模式 (~10 倍慢) |
| 点击 / Return | 切换为文本输入 |
| Return / 点击外部 | 应用输入值 |
| 输入中 Esc / RMB | 取消, 还原之前的值 |
| Tab / Shift+Tab | 下一个 / 上一个字段 |
| 悬停时按 Minus | 取反当前值 |

值得后续复制的额外特性: 多字段纵向拖拽编辑 (按住 X 往下划过 Y 和 Z,
一起滑动调节)。推迟到 v28 之后除非实现成本低。

## 3. 视口导航模型 (Blender + Unity 合并)

当前 NOISE3D 使用 RMB 轨道旋转, 与 Unity 式穿越模式冲突。
采用标准 (Unity 为主, 因用户偏游戏开发; Blender 替代方案写入速查表):

| 动作 | 绑定 |
|------|------|
| 聚焦选中 | F (已有); 锁定跟随: Shift+F (新增) |
| 全景取景 | Home |
| 轨道旋转 | Alt+LMB 拖拽 或 MMB 拖拽 (保留 MMB 自由轨道) |
| 平移 | MMB+Shift 拖拽 或 Alt+MMB |
| 缩放 | 滚轮; Alt+RMB 拖拽 (精细缩放) |
| 穿越模式 | 按住 RMB: 鼠标转向 + WASD 移动, Q/E 升降, Shift 加速, 滚轮调速 |
| 正交切换 | 小键盘 5 (已有) |
| 视图预设 | 小键盘 1/3/7 前/右/顶; Ctrl+小键盘 对面视角 |
| 方向键 | 相机沿地面行走, Shift 加速 |

RMB 当前在视口无其他功能, 穿越模式的占用是安全的。
纯 RMB 轨道旋转被移除 (非标准); MMB + Alt+LMB 覆盖轨道功能。

## 4. 选择语义 (两工具一致)

- 点击空白 = 取消全选
- 点击物体 = 仅选中它
- Shift+Click 切换成员关系 (扩展/缩减)
- 点击已选物体且拖拽小于阈值 = 保持选择
  (来自 Blender generic select 的 `wait_to_deselect_others` 逻辑)
- Ctrl+A 全选; Alt+A / Escape 取消全选
- 双击层级项 = 内联重命名 (Outliner 行为)

## 5. 工作区 (Blender 顶栏)

Blender 事实: 工作区是顶栏中的标签; 每个打包区域+面板;
切换保留每工作区状态。我们的映射 (v26.1-19.0):
标签居中于工具栏, 每工作区面板列表, 折叠状态按工作区持久化,
localStorage 持久化。Blender 还会在打开时记住上次工作区 -- 复制此行为。

---

## 6. 状态栏 (Blender)

Blender 状态栏左半 = 随模式/模态算子变化的上下文键位提示;
右半 = 资源计数 + 版本。模态拖拽期间显示实时值 ("Dx: 1.2 Dy: 0")。
我们的 v26.1-25.0 状态栏必须在以下时机更新提示: Gizmo 模式切换、
模态拖拽激活 (实时增量)、悬停在画布 vs 面板上。

---

## 7. 撤销系统规则 (Blender)

- 撤销入栈仅在算子成功完成后发生
- 被取消的算子不入栈
- 模态运行期间阻止自动保存 (防止手势中途保存) -- 镜像实现:
  任何 ModalDragSession 活跃时暂停自动保存计时器
