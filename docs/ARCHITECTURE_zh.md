# NOISE3D 架构

## 概述

NOISE3D 是一个基于 WebGL2 的浏览器端 3D/2D 场景编辑器。不使用任何第三方 3D 渲染库，所有渲染、数学和场景管理代码均从零编写。

## 模块结构

### 数学库 (`src/math/`)

- **Vec2, Vec3, Vec4**: 向量类型，支持常见操作 (加、减、缩放、点积、叉积、归一化、插值)。
- **Color**: RGBA 颜色类型，支持十六进制转换。
- **Mat4**: 4x4 矩阵，用于变换、透视/正交投影、lookAt、TRS 合成和求逆。

### 场景图 (`src/scene/`)

- **SceneNode**: 场景树中的节点，包含变换 (位置、旋转、缩放)、可见性和父子关系。
- **Scene**: 管理所有节点的容器，支持添加、删除、移动和序列化。

### 渲染器 (`src/renderer/`)

- **Renderer**: WebGL2 渲染核心类。管理着色器程序、网格缓冲、相机、光照和网格渲染。
- **GeometryGenerator**: 程序化网格生成 (立方体、球体、平面、圆柱体、圆锥体)。
- **Material**: 材质定义 (基础颜色、金属度、粗糙度、线框)。
- **Shaders**: GLSL ES 3.00 着色器源码 (网格渲染、网格线、线段绘制)。

### 核心 (`src/core/`)

- **EditorStore**: 基于 Zustand 的全局状态存储。管理场景数据、选择、材质、相机、控制台消息和所有编辑器操作。

### UI (`src/ui/`)

- **App**: 三列布局根组件 (层级 | 视口+控制台 | 检查器)。
- **Toolbar**: 顶部工具栏 (图元创建、网格切换、播放/停止)。
- **ViewportPanel**: Canvas 容器，初始化并驱动 WebGL2 渲染器。
- **HierarchyPanel**: 场景节点树视图 (选择和删除)。
- **InspectorPanel**: 选中节点的属性编辑器 (变换、材质)。
- **ConsolePanel**: 日志输出面板。

## 渲染管线

1. 清除颜色和深度缓冲
2. 设置透视投影和视图矩阵 (lookAt)
3. 渲染网格 (如启用)，使用网格着色器程序
4. 遍历每个可见场景节点:
   - 获取或创建缓存的 GL 网格 (按图元类型)
   - 从 TRS 计算模型矩阵
   - 计算法线矩阵 (模型矩阵的逆)
   - 设置 uniform (模型、视图、投影、法线、材质、光照)
   - 绘制图元

## 着色器细节

主着色器实现 Blinn-Phong 光照:
- 环境光项 (可配置环境光颜色)
- 漫反射项 (方向光)
- 镜面反射项 (Blinn-Phong 半向量模型)

## 状态管理

编辑器使用 Zustand 进行全局状态管理。Store 持有:
- 场景图实例
- 选中节点 ID
- 材质映射 (节点 ID 到材质)
- 相机位置和目标
- 控制台消息
- UI 状态 (网格可见性、播放模式)

React 组件订阅 Store 切片，在状态变更时重新渲染。渲染循环通过 requestAnimationFrame 独立运行，每帧读取当前状态。
