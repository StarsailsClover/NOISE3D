# NOISE3D 路线图: v26.1-09.0 至 v26.1-18.0

## 概述

本文档概述 NOISE3D 接下来 10 个版本, 解决与 Unity 和 Blender 编辑器之间的差距。每个版本提供显著的用户可见改进。

---

## v26.1-09.0 -- 相机系统全面翻修

### 问题
- 初始相机角度歪斜且不直观
- 无视图预设 (前/后/左/右/顶/等轴测)
- 无正交/透视切换
- 居中选中功能不完善

### 变更
- 修复初始相机为标准 45 度等轴测视角看向原点
- 添加视图预设按钮: 前、后、左、右、顶、底、等轴测
- 键盘快捷键: 小键盘 1/3/7 (前/右/顶), 小键盘 5 (透视/正交切换), 小键盘 . (居中选中)
- 视图间平滑相机过渡 (0.3 秒线性插值)
- 正交相机模式 (缩放至光标位置)
- 改进轨道灵敏度 (可配置速度)
- 平移使用屏幕空间投影 (非相机空间)
- 缩放聚焦于光标位置 (非视口中心)
- 相机状态在场景文件中序列化

### 测试
- 相机从等轴测角度启动
- 视图预设按钮正确切换角度
- 小键盘快捷键工作
- 正交/透视切换工作
- 居中选中缩放到正确距离

## v26.1-10.0 -- 变换 Gizmo 实现

### 问题
- Gizmo 模式按钮存在但视口中实际不可拖拽
- 无法在 3D 空间中通过拖拽移动/旋转/缩放物体

### 变更
- 实现交互式移动 Gizmo (X/Y/Z 轴箭头 + 中心平面手柄)
- 实现交互式旋转 Gizmo (X/Y/Z 旋转环)
- 实现交互式缩放 Gizmo (X/Y/Z 缩放手柄 + 中心均匀缩放)
- 对 Gizmo 手柄进行射线测试以确定拖拽轴
- 屏幕空间到世界空间的拖拽增量投影
- 吸附到网格选项 (Ctrl 键)
- Gizmo 大小随距离缩放以保持恒定屏幕尺寸
- Gizmo 绘制在场景之上 (禁用深度测试)
- Gizmo 轴悬停高亮

### 测试
- 选中节点时移动 Gizmo 可见
- 拖拽 X 轴仅移动 X
- 拖拽 Y 轴仅移动 Y
- 旋转 Gizmo 绕正确轴旋转
- 缩放 Gizmo 正确缩放
- Ctrl 吸附到网格工作
- Gizmo 在不同距离保持屏幕尺寸

## v26.1-11.0 -- 多选与场景视图模式

### 问题
- 仅支持单选
- 无线框/实体/渲染视图模式
- 无多对象操作

### 变更
- 框选 (在空白区域拖拽选择多个)
- Shift+点击 添加/移除选择
- Ctrl+A 全选
- 多选变换 (组 Gizmo)
- 场景视图模式: 线框、实体 (无光照)、材质预览、渲染
- 视口工具栏中视图模式切换
- 选择轮廓渲染 (基于模板或后处理)
- 检查器中选择列表显示所有选中节点
- 批量操作: 全部删除、全部复制、分组

### 测试
- 框选选择多个物体
- Shift+点击 切换选择
- 全选工作
- 视图模式切换改变渲染
- 多选 Gizmo 移动所有选中物体
- 批量删除移除所有选中
- 选择轮廓可见

## v26.1-12.0 -- 组件系统与预制体

### 问题
- 无 Unity 风格组件架构
- 无预制体 (可重用对象模板) 系统
- 节点扁平, 无行为附加

### 变更
- 组件接口: onUpdate(dt), onRender(), onInspector()
- 内置组件: MeshFilter, MeshRenderer, Collider, Rigidbody, Camera, AudioSource
- 检查器中的组件面板 (每节点添加/移除组件)
- 预制体系统: 保存节点子树为预制体 (.prefab.json)
- 从资源浏览器实例化预制体
- 预制体覆盖: 修改实例属性, 同步到所有实例
- 组件在场景文件中序列化
- 脚本组件: 附加 .js 脚本到节点, 自动调用 onUpdate

### 测试
- 检查器中可见组件列表
- 可添加/移除组件
- 从选中节点创建预制体
- 从浏览器实例化预制体
- 预制体覆盖和同步
- 脚本组件运行 onUpdate
- 组件序列化/反序列化

## v26.1-13.0 -- 物理引擎 (刚体动力学)

### 问题
- 无物理模拟
- 无碰撞检测
- 重力和力未应用

### 变更
- 自研物理引擎: AABB 和球体碰撞检测
- RigidBody 组件: 质量、速度、角速度
- 碰撞响应 (基于冲量)
- 重力场
- 盒碰撞体和球碰撞体组件
- 物理世界步进 (固定时间步 + 插值)
- 射线投射用于拾取和物理查询
- 碰撞事件 (onCollisionEnter, onCollisionExit)
- 物理调试可视化 (线框碰撞体)
- 播放模式触发物理模拟

### 测试
- 盒子在重力下下落
- 盒子与地面碰撞
- 球碰撞体工作
- 射线投射命中正确物体
- 碰撞事件触发
- 物理调试叠加层切换
- 非播放模式时物理暂停

## v26.1-14.0 -- 节点式材质编辑器

### 问题
- 材质是硬编码参数列表
- 无可视化着色器图
- 无法创建自定义着色效果

### 变更
- 节点图编辑器 UI (拖拽节点, 连接引脚)
- 材质节点类型: 输出、颜色、纹理、混合、数学、向量、法线
- 着色器图编译为 GLSL/WGSL
- 实时材质预览球
- 保存/加载材质图 (.mat.json)
- 材质资源浏览器集成
- 节点搜索和分类
- 连接验证 (类型检查)

### 测试
- 材质编辑器打开节点图
- 可从面板添加节点
- 可连接节点引脚
- 编译生成有效着色器
- 预览球实时更新
- 材质保存/加载工作
- 类型不匹配阻止连接

## v26.1-15.0 -- 地形与环境系统

### 问题
- 无地形编辑
- 无天空盒/环境
- 无雾或大气

### 变更
- 带高度图的地形网格 (高度刷、平滑刷、展平)
- 地形纹理混合 (最多 4 层)
- 高度图导入/导出 (16 位 PNG)
- 笔刷大小和强度控制
- 天空盒: 渐变天空、立方体贴图、等距矩形
- 程序化天空 (太阳位置, 大气散射)
- 雾: 线性和指数
- 环境光照 (从天空盒 IBL)
- 大型地形 LOD

### 测试
- 地形以默认高度图创建
- 高度刷提升地形
- 平滑刷工作
- 纹理混合显示图层
- 天空盒渲染
- 雾影响远处物体
- 高度图导出工作

## v26.1-16.0 -- UV 编辑与程序化几何

### 问题
- 无 UV 编辑
- 仅基本图元, 无程序化网格生成
- 无法在编辑器内创建自定义几何体

### 变更
- 选中网格的 UV 展开 (平面、盒形、球面投影)
- UV 编辑器视口 (2D UV 空间, 网格叠加)
- UV 变换 (移动、旋转、缩放 UV 岛)
- 程序化几何: 挤出、倒角、细分、布尔运算
- 网格编辑模式: 顶点/边/面选择
- 自定义网格从编辑器保存为 OBJ
- 几何节点系统 (参数化形状)

### 测试
- UV 展开生成有效 UV
- UV 编辑器显示网格叠加
- UV 变换工作
- 挤出创建新面
- 细分增加多边形数量
- 编辑模式中顶点选择
- 自定义网格导出为 OBJ

## v26.1-17.0 -- 动画系统 V2 (曲线与绑定)

### 问题
- 动画仅基本关键帧
- 无动画曲线
- 无骨骼/绑定
- 无动画层

### 变更
- 动画曲线编辑器 (关键帧间贝塞尔插值)
- 曲线操作: 切线手柄, 缓动预设
- 骨骼绑定: 骨骼层级, 蒙皮
- 骨骼权重绘制
- 逆运动学 (IK) 求解器
- 动画层 (基础 + 叠加)
- 动画混合树
- 根运动支持
- 动画事件 (关键帧时间触发回调)

### 测试
- 曲线编辑器显示贝塞尔手柄
- 切线操作改变插值
- 骨骼层级正确创建
- 蒙皮变形网格
- IK 求解器到达目标
- 动画层混合
- 动画事件在正确时间触发

## v26.1-18.0 -- 插件系统与可扩展性

### 问题
- 用户无法扩展编辑器
- 无自定义面板、工具或组件
- 一切都是硬编码的

### 变更
- 插件 API: registerPanel, registerTool, registerComponent, registerNodeType
- 插件清单格式 (.plugin.json)
- 插件管理器 UI (启用/禁用, 从 URL 安装)
- 内置插件示例 (截图工具, CSV 导入器)
- 事件系统 (onSceneLoad, onNodeSelect, onRender, onUpdate)
- 插件沙箱 (有限 API 访问)
- 开发期间插件热重载
- 脚本 API 扩展 (从脚本完全控制编辑器)

### 测试
- 插件管理器显示已安装插件
- 来自插件的自定义面板渲染
- 来自插件的自定义工具工作
- 插件启用/禁用工作
- 插件事件正确触发
- 热重载无需刷新页面更新插件

## 优先级顺序

1. **相机** (v09) -- 最立即可感知, 阻碍所有其他功能的有效使用
2. **Gizmo** (v10) -- 核心编辑交互, 没有 Gizmo 无法搭建场景
3. **多选** (v11) -- 必备工作流功能
4. **组件** (v12) -- 物理和脚本的架构基础
5. **物理** (v13) -- 依赖组件
6. **材质编辑器** (v14) -- 视觉质量提升
7. **地形** (v15) -- 场景构建能力
8. **UV/程序化** (v16) -- 几何创作
9. **动画 V2** (v17) -- 依赖良好的曲线编辑
10. **插件** (v18) -- 长期增长的可扩展性
